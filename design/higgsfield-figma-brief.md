# Higgsfield · Figma 후속 제작 브리프

상태: 실행 도구 미노출로 외부 작업 미실행. 아래는 실행 가능한 도구가 제공될 때 사용할 제작 명세다.

## Higgsfield

입력: `public/images/product/controller.png`. 사용자가 제공한 실제 올리브색 제어 본체 사진. 설치 모습은 `installed-front.png`, `installed-side.png`.

영상 방향: 5초 정도의 차분한 제품 소개. 정면 3/4 원본 시점을 유지하고 아주 작은 카메라 전진과 부드러운 빛 변화만 적용한다. 본체의 올리브색 외장, 흰색 전면, 검은 개구부, 하단 돌출부와 비율을 보존한다. 보이지 않는 뒷면, 새 통풍구, 로고, 디스플레이, 내부 기구를 만들어내지 않는다. 벌·비행 효과·과장된 입자 효과·문자·측정값은 넣지 않는다. 성능 데이터와 UI는 웹에서 별도로 렌더링한다. 영상 자동재생 여부는 사용자 동작 줄이기 설정을 존중한다. 먼저 지원 모델/프리셋을 확인하고 실행한 작업 ID로 완료 여부와 실제 결과를 추적한다.

## Figma

대상: 신규 제품 소개 디자인. 데스크톱 1440px, 모바일 390px.

- 아이보리 #f7f7ef, 잉크 #202b23, 올리브 #607344. 제목과 제품 사진을 크게, 앱 체험을 인접 배치.
- 실제 본체와 설치 사진 3종. 제품 사진 확대 상태 및 사진 전환 상태.
- 휴대폰: 스마트벌통/측정 기록, 26.5°C 초기 설정, 설정 변경/적용 상태, 8개 측정 기록, 원본 모달.
- 성능 그래프: 26.5°C 목표선, 원본 측정값 8개, 시간 선택 상태. 그래프 데이터는 `src/app/_components/hiveRecord.ts`에서 가져온다.
- 모션: 사진 전환 opacity 0.4→1, 0.5초. 마우스 반응 ±4px/±3px, 0.45초 cubic-bezier(.2,.65,.3,1). 실제 웹 조작은 native controls로 유지한다.
- Figma Motion API 지원 여부 확인. metronome 미지원이면 해당 API 사용을 중단하고 정적 상태 시안으로 정리한다. 캔버스 작성 시 auto-layout을 사용하고 모든 변경 노드 ID를 반환한다.

검토 참고: `hardware-phone-hero.png`, `hardware-phone-mobile.png`, `phone-records-mobile.png`, `performance-desktop.png`.
